Team Sync

Share one workspace across your team’s browsers through a small server you run yourself. This is a beta built for a few people who trust each other — it is not enterprise collaboration.

  • One shared passphrase. No individual accounts, roles, or way to remove one person’s access — anyone with the workspace name and passphrase can read and change everything.
  • Whole-workspace sync. If two people edit at once, you choose whose version to keep.
  • Your data leaves this browser. The workspace goes to the server you enter below (use https://), and the passphrase is saved unencrypted in this browser.
  • Leave this disconnected and the app works exactly as before, saved only in this browser.
